# 20 — Competitive Notes

Use this document as positioning guidance, not as a frozen market report.

## Adjacent categories

### Stack directories / discovery
Products in this category help users discover tools and see what stacks others use.

Our difference:
- personal intent
- exact component preference
- project composition
- AI-decision delegation
- compiled agent context

### Coding-agent rule managers
These synchronize persistent coding instructions across agents.

Our difference:
- rules are generated from a richer structured Developer System of Record
- stack/components/themes/templates/repositories are first-class objects
- project wizard exists before codebase context

### Project/codebase memory
These help agents understand an existing repository.

Our difference:
- starts before repository creation
- describes how the user wants to build
- reusable across future projects

### Documentation context tools
These give agents current library docs.

Potential integration, not necessarily direct competitor.

## Strategic moat candidates

Weak moat:
- markdown prompt generation
- bookmarks
- generic AI chat

Stronger:
- accumulated personal engineering graph
- project inheritance/history
- high-quality curated compatibility data
- exact reusable components/templates
- workflow integrations
- team engineering standards
- trusted import/export adapters

## Positioning sentence

"Your personal engineering system, compiled into the right context for every project and coding agent."
