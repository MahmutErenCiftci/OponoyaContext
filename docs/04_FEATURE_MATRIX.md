## MVP killer features

1. Exact component/resource memory.
2. `LOCKED / PREFERRED / AI_DECIDE / DISABLED`.
3. Guided Project Wizard.
4. Project overrides.
5. Live deterministic Context Compiler.
6. Multi-agent export.

If these six are weak, Discovery will not save the product.
