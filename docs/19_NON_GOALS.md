# 19 — Non-goals

These protect product focus.

## Not an IDE
Do not build a browser code editor in V1.

## Not GitHub
Do not host git repositories.

## Not a full package registry
We link/index resources; we do not mirror npm/GitHub.

## Not a BaaS
No database/auth/storage infrastructure sold to users.

## Not an autonomous software company
The product provides context/decisions to coding agents. It does not need multi-agent project management in the MVP.

## Not a prompt marketplace
Prompts/templates are resources, not the entire product.

## Not a universal crawler
Discovery starts curated.

## Not a design tool
Themes/components can be stored and referenced, but no Figma replacement.

## Not a deployment platform
Deployment profiles/instructions can be managed. Hosting user apps is out of V1.

## Not an AI that secretly rewrites choices
User decisions remain explicit and auditable.
