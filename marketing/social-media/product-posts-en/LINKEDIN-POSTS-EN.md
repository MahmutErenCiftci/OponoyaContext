## 3. You set the boundaries for AI

**Visual:** `03-set-ai-boundaries.png`

Asking AI to write code is only part of the job. You also need to define which technical decisions it must follow.

Oponoya Context gives every technology choice one of four decision modes:

• **Locked:** AI cannot change the decision.  
• **Preferred:** Use this choice first.  
• **Let AI decide:** Choose based on the project context.  
• **Disabled:** Do not use this technology or approach.

These modes replace vague prompt instructions with clear operating rules. AI knows where it has flexibility and where it must follow your decisions.

You define the boundaries. Your AI coding tools work with clearer context.

## 4. Create one context, export it to any agent

**Visual:** `04-export-context-to-agents.png`

You should not have to rewrite the same project instructions for Codex, Claude Code, Cursor, and GitHub Copilot.

Oponoya Context turns your technology choices, decision modes, and project rules into structured context. You can then export it in the format used by your preferred AI coding tool:

• Master Prompt  
• AGENTS.md  
• CLAUDE.md  
• Cursor `.mdc` rules  
• GitHub Copilot instructions

Your tools may change, but your technical decisions remain consistent. Update the source context and generate the output you need.

One context. Multiple AI coding tools.

## 5. 246 technologies, better-informed choices

**Visual:** `05-technology-catalog.png`

Technology decisions deserve more than a popularity list.

The Oponoya Context catalog includes 246 technologies and 15 ready-made stacks. Explore strengths, tradeoffs, alternatives, and tools that work well together in one place.

The catalog also contains AI readiness assessments for 50 technologies and development velocity assessments for 28 technologies. Criteria such as documentation quality, community support, AI readiness, and token efficiency are presented on a clear 1–5 scale.

These scores are editor assessments designed to support decisions, rather than live performance benchmarks.

The goal is not to show you more tools. It is to help you ask better questions before choosing one.
